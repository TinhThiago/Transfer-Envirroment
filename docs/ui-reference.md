# PH UI reference

Nguồn do người dùng cung cấp: https://ph-ui-library.khoitran.chatgpt.site/#data

Đã đọc HTML, `ph-design-brief.md` và `ph-tokens.json` công khai ngày 15/10/2026. Không có browser surface khả dụng trong session (`cua.getState` trả browsers=[]); chưa đối chiếu ảnh chụp trực quan.

Áp dụng walnut #7A4E1D, walnut dark #5B3E1C, gold #C89A5B, nền #F8F9FA, surface trắng, border #E9ECEF, selected navigation #F3ECE2. Heading Montserrat, body Roboto; h1 30px, body 15px, caption 13px. Control 40px, radius 6px; surface radius 8px. Global header 42px. Bố cục sidebar + page, table có command bar, chọn checkbox và pane xem kế hoạch. Tái dùng nguyên tắc ưu tiên bảng và thao tác, không sao chép dataset demo hoặc thêm cấu hình ngoài phạm vi.

Chưa tuyên bố đã đối chiếu trực quan với mẫu; sẽ giữ giới hạn này trong biên bản kiểm chứng.
